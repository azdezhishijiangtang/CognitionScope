# CognitionScope v11

**个人学习记录与观测平台** —— 记下学了什么、按时复习、看看趋势。

纯前端、零依赖、零构建步骤：**双击 `index.html` 就能用**，数据只存在你这台设备的浏览器里，不上传、断网也能用。

支持**日光 / 月光双主题**：右上角一键切换（白色明亮 / 深色夜航），首次访问自动跟随系统外观，选择会记住。详细条款见文末[「许可与版权」](#许可与版权)。

> **版权提示**：本仓库**保留所有权利**，未采用任何开源许可证。复制、转载、复用或商业使用前请先阅读 [`LICENSE`](LICENSE)。

> **v11 是「打开就有东西可看」的版本。** v10 把界面做得普通人能看懂了，但方法学骨架里是空的：检索没东西可搜、知识网络 0 节点、复习队列空空如也，新用户面对的是一堆空白输入框。v11 补上一批**原创编写、带答案 / 要点 / 常见错因 / 分层提示**的示例内容，并配套学科分类词表、错因分类和先验知识网络——**默认一条都不写入你的数据**，想试用点一下「载入示例」，试完一键清除。

## 三分钟看懂

| 你想做的事 | 点这里 | 会得到什么 |
|---|---|---|
| 第一次打开，不知道从哪开始 | **示例内容馆** | 46 条现成示例，随便翻、随便试，不用先录任何东西 |
| 记一条要背的内容 | **录入 / 档案** | 内容和答案存进本机，之后才能排复习 |
| 今天该复习什么 | **今日复习** | 到期的条目排成一队，先回忆再对答案 |
| 看看自己学得怎么样 | **观测站** | 未来一周负荷、哪段时间状态好、今天该做什么 |
| 换电脑 / 怕丢数据 | **数据与导出** | 导出一份文件，换设备再导入 |
| 有个词看不懂 | **名词解释** | 全站黑话的一句话白话对照，可搜索 |

**第一次打开会停在「开始使用」页**：三步上手 + 全部 18 个页面的白话地图 + 「它不是什么」的诚实说明。照着点就行，不用先学任何概念。

### 示例内容馆：默认零写入

| 动作 | 会发生什么 |
|---|---|
| 只浏览（默认） | 什么都不会写进你的数据。可以按学科、难度、关键词筛选，展开看答案、评分标准、要点清单、常见错因，提示一次只多给一条 |
| **载入示例到我的库** | 你主动点才会发生。46 条示例进入复习队列、负荷图和知识网络，方便试用功能；顶部出现「演示模式」横幅 |
| **清除我载入的示例** | 只删带演示标记的条目，你自己记的内容一条都不动 |
| **只导出示例包** | 导出一个只含示例的 JSON，不含你的任何学习记录 |

**演示内容不等于成绩**：示例条目带 `demo:true` + `demoVersion` + `source` 三重标记，统一被 `CS.fitParams()`、`CS.buildPCM()`、`CS.exportJSON()` 和 `EXPORTM.buildBundle()` 排除——**不计入经验正确率、个人学习数据档案，也不会出现在任何导出包里**。演示期间若做了复习，由此产生的事件会按 append-only 规则留在流水账里，不可抹除。

> 示例文本是本项目原创编写，只借鉴了外部仓库的**字段结构**（课程→章节→知识点、要点 / 错因 / 分层提示 / 先验边），没有复制任何原文。完整来源与版权说明见 `ATTRIBUTION.md`。

### 看不懂怎么办（四层解释）

1. **每页顶部的「本页说明」卡** —— 固定三栏：*这页干嘛 / 我该点哪里 / 结果怎么读*，再列出「本页名词」，点一下就出白话解释。看熟了可以点「收起说明」或右上角关掉。
2. **名词解释页** —— 70+ 条术语的白话词典，支持搜索和按类筛选（基础 / 记录 / 复习 / 统计 / 隐私 / 数据 / 示例 / 学科）。
3. **导航白话副标题** —— 每个页签下面一句话，比如「校准与模型」下面写着「预测准不准」。
4. **分组导航常驻可见** —— 分「日常使用」和「进阶功能」两组，全部看得见，并明确标注「日常可跳过」。

> **通俗说明开关**在右上角，默认开启。关掉后界面回到干净的专业视图，功能一个不少。

```bash
# 双击 index.html，或
python3 -m http.server 8080
```

无需 `npm install`。Node.js 18+ 只用于跑测试。

## 测试

```bash
npm test                 # 全量：逻辑 + v9 能力 + v10 通俗层 + v11 示例包 + 历史回归 + 文档门禁 + 浏览器检查
npm run check            # 逐文件语法检查
npm run test:demo        # 只跑 v11 示例内容包测试
npm run test:plain       # 只跑通俗化层测试
npm run test:legacy      # 只跑历史回归
npm run test:docs        # 只跑文档-实现一致性门禁
npm run test:browser     # 真实 Chromium file:// 检查
npm run build:manual     # 从磁盘源码重新生成《完整代码手册》
```

**通过数一律以命令输出为准，不写死在文档里。** 一致性门禁会检查：所有测试文件都已登记、每页说明与术语词典完整、说明引用的黑话必须能在词典查到、示例包默认不写入 / 来源字段齐全 / 导出剔除闸门存在 / 版权声明随包交付、手册与磁盘源码逐字一致。新增页面或测试漏登记会直接让测试失败。

> 测试文件名里的 `v5` / `v6` / `v7` 是历史资产命名，保留以维持可追溯性，不代表当前应用版本。

## 文档维护规则

1. **单一事实来源** `PROJECT-FACTS.json`：版本、schema、套件清单、隐私边界、v9/v10/v11 模块与能力、示例包登记。
2. **手册自动生成** `npm run build:manual`：附录由磁盘源码逐字生成（含 `ATTRIBUTION.md`），杜绝过期副本。
3. **一致性门禁** `npm run test:docs`：手册过期、版本漂移、套件漏登记、说明层缺失、示例隔离闸门缺失都会让 `npm test` 失败。

改代码后：`npm run build:manual` → `npm test`。

## 诚实声明

**没有变的部分**：本平台不是大脑模型 / 标准化测验 / 医疗器械，不做诊断；不输出 z 分数、人群百分位或能力画像；N=1 结果不可推广；完整配对仍是 complete-case；本地 FNV 链与 HMAC 锚点都不是密码学防伪；PII 检测只是启发式拦截；合成数据实验只验证方法可行性；B/C/D 级指标必须附 n、时间范围、definitionVersion 与同屏免责。

**v11 补的是内容，不是把这些限制修好了**：示例文本只换来「有东西可试用」，统计口径一个字没改；学科题目**没有**被填进 `lab.js` 的 `NORMS` 占位常模（五项仍 `source: null`），**没有**接入 AI 外发路径，**没有**扩大白名单，**没有**静默写进用户数据或导出包。仍未完成：真实厂商 API 合约测试、跨浏览器兼容矩阵、API Key 后端代理化。

## 外部 AI（可选）与隐私边界

- **API Key 与完整性口令仅驻留当前页面内存**，刷新后需重新输入；不写入 localStorage、L1/L2 或导出包。
- 唯一网络出口 `AI.researchQuery()` 支持流式与重试；请求体只有固定 system prompt + 手动输入的通用研究问题 + `stream` 开关。运行前经 `AI.assertAllowedUrl()` 与 CSP 双重限制；勾选框只是界面确认，不存在「功能级逐次同意网关」。
- 个人数据外发功能已关闭，涉及个人数据的 AI 接口一律拒绝；示例内容不进入任何请求体；服务商仍会收到问题文本、API Key 与请求元数据。
- **正式部署应改用后端代理**，不要把 Key 放在前端。

详见 `SECURITY-PRIVACY.md`、`ATTRIBUTION.md` 与 `CHANGELOG.md`。
